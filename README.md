# Hangman Word Guessing Game

## Project Description
Hangman is a simple word-guessing game developed using Python. The computer randomly selects an English word, and the player must guess the word by entering one letter at a time.

## Objectives
- Develop a console-based game using Python.
- Understand random word selection.
- Practice Python functions and loops.
- Learn file handling.
- Implement input validation.

## Technologies Used
- Python 3
- VS Code
- Random Module
- English Words Dataset

## Features
- Random English word selection.
- Six incorrect attempts.
- ASCII Hangman drawing.
- Letter validation.
- Duplicate letter prevention.
- Win and lose conditions.
- Replay option.

## Project Files
- hangman.py – Main Python program.
- english_words.txt – English word dataset.

## How to Run
1. Install Python 3.
2. Download the project files.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute:

   python hangman.py

## Conclusion
This project helped me understand Python programming concepts such as functions, loops, conditional statements, sets, random selection, and file handling.
